# Physical AI & Humanoid Robotics - Code Examples

This directory contains code examples that demonstrate the concepts covered in the Physical AI & Humanoid Robotics course.

## Examples Included

### 1. Basic Physical AI Demo (`physical_ai_demo.py`)
A simple demonstration of key Physical AI concepts including:
- Robot state representation
- Perception system
- Path planning
- Simple control
- Natural language processing
- Basic visualization

### 2. Simulation Environment (`physical_ai_simulation.py`)
A more advanced simulation environment demonstrating:
- Robot-environment interaction
- Obstacle avoidance
- Command queueing
- Basic navigation
- Object manipulation
- Animation and visualization

### 3. Integrated System (`integrated_physical_ai_system.py`)
A comprehensive example integrating all major components:
- Perception system with environment modeling
- Advanced path planning with multiple algorithms
- Natural language processing for command understanding
- Task planning and action sequencing
- Low-level control system
- Safety monitoring
- Complete system integration

## Running the Examples

### Prerequisites
Make sure you have Python 3.7+ installed along with the following packages:
```bash
pip install numpy matplotlib
```

### Running Examples

1. **Basic Demo**:
```bash
python physical_ai_demo.py
```

2. **Simulation**:
```bash
python physical_ai_simulation.py
```

3. **Integrated System**:
```bash
python integrated_physical_ai_system.py
```

## Key Concepts Demonstrated

Each example progressively builds on the previous ones to demonstrate:

- **Perception**: Sensing and understanding the environment
- **Planning**: High-level task planning and low-level path planning
- **Control**: Low-level action execution
- **Interaction**: Natural language understanding and response
- **Integration**: Combining all components into a cohesive system
- **Safety**: Monitoring and ensuring safe operation
